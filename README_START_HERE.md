# ĐÀI QUAN SÁT MOPD — TRỌN BỘ (v0–v5)

**Bắt đầu:** mở `latest/mopd-course-research-edition-v5-learning-science.html` trong trình duyệt.

Thư mục:
- `latest/` — website phiên bản mới nhất, có Learning Science v5.
- `versions/` — bản gốc và các phiên bản Research Edition v1–v4 để đối chiếu.
- `docs/` — README các phiên bản và Learning Science research notes.
- `curriculum_data/` — các CSV về mức bao phủ bài học.
- `labs/` — ví dụ và lab Python (MOPD, RLCR, v2 examples).
- `previews/` — hình kiểm tra giao diện qua các phiên bản.
- `source_and_tests/` — script xây và test của v5 (dành cho người chỉnh sửa).
- `MANIFEST_SHA256.txt` — checksum các file đi kèm.

**Lưu ý:** Một số tài nguyên của HTML (ví dụ Google Fonts / KaTeX CDN) cần Internet; đăng nhập/đồng bộ chỉ hoạt động khi có backend phù hợp. Các kết quả lab minh họa không thay thế việc tái lập kết quả các papers.

Bản gốc và từng phiên bản được giữ tách biệt, không ghi đè. Các zip lịch sử không được lồng vào vì nội dung đã được giải nén thành các thư mục tương ứng.
